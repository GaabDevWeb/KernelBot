## Enunciado

Olá, Gabriel,

Chegamos ao momento mais importante do nosso projeto: A entrega final!

Após a última entrega, seu cliente está muito confiante que iremos conseguir realizar a entrega completa. Agora é o momento de verificar a completude do projeto, implementar os componentes faltantes e criar os testes para consolidar a nossa entrega.

Contexto: Sob a supervisão do professor do Projeto de Bloco, os alunos enfrentam o desafio de desenvolver um projeto em um contexto corporativo, respondendo a uma demanda urgente de um cliente que necessita de um sistema específico. Com um prazo inicial de cinco meses para a entrega, a equipe planeja realizar cinco entregas principais, visando garantir a agilidade e a adaptação do projeto às necessidades do cliente, inclusive frente a mudanças nos requisitos. Quatro entregas já foram realizadas. Após definir os requisitos na primeira fase; mapear os casos de uso na segunda etapa; modelar classes e relacionamentos na terceira etapa e lidar com mudanças de requisitos na quarta entrega; iremos consolidar a última entrega. Este projeto adota o método RUP (Rational Unified Process) de desenvolvimento, e agora finalizamos a fase de Construção. 

Diretrizes:

Implementar todas as componentes de software restantes baseado no projeto realizado. O resultado final do projeto deve ser apresentado em um dos dois formatos: 
Interface de linha de comando que interage com um back-end por meio de uma API REST em Java.
Interface e back-end usando Razor Pages (C#/ASP.NET) 
A implementação de persistência foi feita até o TP4 usando arquivos CSV, contudo ao optar pela implementação usando Razor Pages (C#/ASP.NET) a persistência pode ser reimplementada com EF Core.

Entrega do Projeto:

A entrega final deve incluir todos os documentos e artefatos gerados durante o projeto, seguindo as diretrizes acima. Os alunos são encorajados a aplicar criatividade e pensamento crítico ao longo do desenvolvimento do projeto, visando a criação de um sistema que não apenas atenda aos requisitos técnicos, mas também ofereça uma experiência significativa e valiosa aos usuários finais.

Assim que terminar, salve seu trabalho em PDF nomeando o arquivo conforme a regra “nome_sobrenome_PB_TP5.PDF” e poste como resposta a este TP.
